Paste ChatGPT's reply (or type a command). The relay extracts the grammar from a noisy reply.

Grammar 
STANCE rush|zone|turtle|bait|anti-air
SPACING 24-400
AGGRESSION 0-1
GOFOR none|light|heavy|special|combo
TAUNT a short callout (max 80 chars)

One-liner also works:  rush spacing=80 aggro=0.8 go=special taunt=come on
The join code is not stored on the server in plain text, is not written to the URL, and should never be pasted into a public chat. See docs/COMMANDER.md.
